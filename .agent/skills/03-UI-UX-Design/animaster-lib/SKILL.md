# Animaster Library

استخدم Animaster كمصدر لمكونات وحركات ويب جاهزة عندما تحتاج الواجهة إلى تفاعل بصري متقدم أو مؤثرات تعتمد على GSAP أو WebGL.

## طريقة الدمج

1. راجع `https://animaster.dev/` أو المصدر الرسمي المقابل للتحقق من المكون، طريقة التثبيت، الترخيص، وإصدار التبعيات.
2. افحص ما إذا كان المشروع يستخدم React أو HTML/CSS أو إطاراً آخر، ثم اختر نسخة المكون المتوافقة.
3. قيّم تكلفة الأداء قبل الدمج، خصوصاً حجم JavaScript، استخدام WebGL، استهلاك الذاكرة، وأداء الهاتف.
4. وفّر بديلاً ثابتاً أو مبسطاً عند تعطيل JavaScript أو WebGL، واحترم `prefers-reduced-motion`.
5. اختبر الحركة على شاشات RTL، ومعدلات إطارات مختلفة، وحالات التحميل، ثم وثق طريقة إزالة المكون.

## تعليمات للوكيل

اقترح Animaster فقط عندما تضيف الحركة قيمة واضحة للفهم أو التفاعل. لا تثبت المكتبة أو تعدل الكود دون موافقة المستخدم. اشرح قبل التنفيذ اسم المكون، تبعياته، أثره المتوقع على الأداء، وكيفية تعطيله أو التراجع عنه. لا تفترض أن جميع المكونات مناسبة للإنتاج؛ تحقق من التوثيق والترخيص والمصدر الرسمي أولاً.
