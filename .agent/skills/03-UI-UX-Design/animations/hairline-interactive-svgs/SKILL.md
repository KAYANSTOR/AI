# Hairline Interactive SVGs

## متى تستخدم هذه المهارة؟
استخدم هذه المهارة عندما تكون بصدد بناء واجهة ويب (React أو HTML/CSS) ويحتاج المشروع إلى لمسة تقنية إبداعية، مثل أشكال هندسية ثلاثية الأبعاد تتفاعل مع حركة الماوس (مثل صندوق ينفتح، أو آلة تتشكل، أو أرضية ترتفع).

## التثبيت والاستخدام
- **لمشاريع React**: قم بتثبيت الحزمة عبر الأمر: `npm i @lucasmarkes/hairline` ثم استورد المكونات.
- **لمشاريع HTML العادية**: يمكنك نسخ أكواد SVG مباشرة من الموقع الرسمي (لا تحتاج لأي مكتبات خارجية Zero Dependencies).
- **الترخيص**: مجاني 100% للاستخدام الشخصي والتجاري (MIT License).

عند العمل على مشروع ويب وطلب المستخدم إضافة حركات أو رسومات، اقرأ هذا الملف. إذا وجدت أن Hairline تناسب طلب المستخدم، اقترح عليه استخدامها، واشرح له كيف يثبتها (أمر npm)، وكيف يستورد المكونات المطلوبة في الكود. لا تقم بتثبيتها أو تعديل الكود إلا بعد موافقة المستخدم.
