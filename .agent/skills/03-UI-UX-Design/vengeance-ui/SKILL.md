# VengeanceUI

استخدم VengeanceUI كمكتبة مكونات جاهزة لمشاريع React التي تعتمد على Tailwind CSS وتحتاج إلى تأثيرات وحركات مبنية على Framer Motion.

## المصدر والتكامل

- المصدر: `https://github.com/Ashutoshx7/VengeanceUI`
- افحص `package.json` وإعدادات Tailwind قبل إضافة أي مكون.
- راجع التوثيق ونسخة الحزمة الحالية من المصدر الرسمي، ولا تنسخ مكوناً يعتمد على تبعية غير موجودة في المشروع.
- عدّل tokens والألوان والمسافات لتتطابق مع نظام التصميم بدلاً من إدخال قيم متعارضة.

## قواعد الاستخدام

1. افحص بنية المشروع واتجاهه، خصوصاً عند بناء واجهة عربية RTL.
2. اختر أصغر مكون يحقق الحاجة، وتجنب إضافة مكتبة كاملة إذا كان المطلوب مكوناً واحداً بسيطاً.
3. اختبر المكون على الهاتف ولوحة المفاتيح وقارئ الشاشة، وتحقق من حالات loading وempty وerror.
4. احترم `prefers-reduced-motion` ولا تجعل الحركة شرطاً لفهم المحتوى أو تنفيذ الإجراء.
5. لا تثبت VengeanceUI أو تعدل الكود قبل موافقة المستخدم، وقدّم أولاً خطة الدمج والتبعيات.
