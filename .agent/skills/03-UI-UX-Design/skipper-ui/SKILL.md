# Skipper UI

استخدم Skipper UI كمصدر لمكونات React الجاهزة عندما يحتاج المشروع إلى واجهة حديثة مبنية على نمط ShadCN مع حركات تعتمد على Framer Motion.

## طريقة الاستخدام

1. افحص المشروع أولاً وحدد إطار React ونظام التصميم الحالي قبل إضافة مكون.
2. راجع الموقع الرسمي `https://skiper-ui.com/` واختر المكون المناسب وإصداره وطريقة تثبيته.
3. تحقق من توافق المكون مع RTL والعربية، ونظام الألوان، وإمكانية الوصول، وحجم الحزمة.
4. انسخ أو ثبت المكون داخل بنية المشروع الحالية، وادمجه مع primitives الموجودة بدلاً من إنشاء نسخة مكررة.
5. احترم `prefers-reduced-motion` واختبر الحركة على الأجهزة الضعيفة والشاشات الصغيرة.

## تعليمات للوكيل

اقرأ هذه المهارة قبل اقتراح Skipper UI. لا تثبت حزم أو تعدل الكود دون موافقة المستخدم. عند الحاجة، اذكر اسم المكون، مصدره، تبعياته، أثره على الحزمة، وخطة التراجع. لا تفترض أن API المكون ثابت؛ تحقق من الموقع الرسمي قبل كتابة الاستيراد النهائي.
