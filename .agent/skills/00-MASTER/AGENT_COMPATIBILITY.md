# توافق الوكلاء وأدوات التطوير

يُعد الكتالوج مصدراً للملفات والتعليمات، وليس ضماناً بأن كل أداة ستكتشف المهارات تلقائياً. يجب على الوكيل قراءة `SKILL.md` صراحةً إذا لم يكن دعم Agent Skills مفعلاً.

| الأداة | مسار المشروع المقترح | طريقة الاكتشاف | الحالة |
| --- | --- | --- | --- |
| Claude Code | `.agent/skills/` أو المسار الرسمي في الإصدار المستخدم | تثبيت مجلد المهارات ثم ذكر المسار | يحتاج تحققاً حسب الإصدار |
| Codex | `.agent/skills/` أو المسار الرسمي في الإصدار المستخدم | توجيه صريح إلى `SKILL.md` | يحتاج تحققاً حسب الإصدار |
| Cursor | `.agent/skills/` داخل المشروع | ذكر مسار المهارة في الطلب أو تكامل المشروع | يحتاج تحققاً حسب الإصدار |
| Gemini CLI | مجلد المهارات الذي تدعمه الإضافة | تثبيت الإضافة/التكامل ثم ذكر المسار | يحتاج تحققاً حسب الإصدار |
| VS Code | `.agent/skills/` أو تكامل الوكيل المستخدم | توجيه صريح إلى الملف | يعتمد على الإضافة |
| Antigravity | مسار Agent Skills الموثق في نسخة الأداة | لا يُفترض مسار تلقائي | يحتاج تحققاً |
| Manus والوكلاء السحابيون | `.agent/skills/` داخل مساحة العمل | قراءة الملف صراحةً أو عبر تكامل الوكيل | مدعوم بالتوجيه الصريح |

قبل استخدام Figma أو Adobe أو بوابات الذكاء الاصطناعي، تحقق من MCP أو الحزمة أو بيانات الاعتماد المطلوبة. لا تضع إعدادات المصادقة في الكتالوج.
