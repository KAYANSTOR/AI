# مهارات مشروع KAYAN AI

تم تثبيت هذه المهارات محلياً للمشروع من مصدرين عامين:

- `replica-*`: مهارات clean-room للاستكشاف، التخطيط، التصميم، البناء، الاختبار، المقارنة، العلامة التجارية والإطلاق.
- فئات `00-MASTER` إلى `08-Security-Auditing`: كتالوج مهارات KAYANSTOR لسير العمل والهندسة وواجهة المستخدم وNext.js وSEO والأمان.

عند تنفيذ خطة المشروع، استخدم المهارة المتخصصة المناسبة قبل التعديل، واقرأ `SKILL.md` الخاص بها. لا تنسخ كود أو علامات أو محتوى مملوكاً من المنتج المقارن؛ استخدم البحث لفهم الوظائف والتدفقات فقط.
