# KAYAN AI

منصة عربية لاستقبال العملاء آلياً: وكيل ذكي يرد على واتساب وإنستغرام والرسائل النصية والمكالمات، يحجز المواعيد، يسجّل العملاء المحتملين، ويحوّل المحادثة لموظف عند الحاجة، مع لوحة تحكم كاملة لإدارة النشاط.

## الميزات

- **الإعداد السريع:** إنشاء حساب الشركة، اختيار نوع النشاط، إدخال البيانات والخدمات، ثم ربط قناة وتفعيل الوكيل.
- **وكيل الذكاء الاصطناعي:** تخصيص الاسم واللغة والأسلوب، نسخ التعليمات مع إمكانية الاستعادة، وسياسات تحكم في الأدوات المسموح بها.
- **قاعدة المعرفة:** حقائق النشاط وأسئلته الشائعة، يعتمد عليها الوكيل ولا يخترع إجابة غير موجودة.
- **القنوات:** واتساب وإنستغرام عبر Meta، والرسائل النصية عبر Twilio، والهاتف عبر Vapi، مع تحقق من توقيع كل webhook.
- **صندوق المحادثات:** متابعة المحادثات، التعيين، التصعيد لموظف بشري، والردود الجاهزة.
- **العملاء والمواعيد:** جهات الاتصال، العملاء المحتملون، الخدمات، ساعات العمل، المواعيد والتذكير بها.
- **المبيعات:** عروض الأسعار والطلبات لأنواع الأنشطة التي تحتاجها.
- **الأتمتة:** مسارات عمل، حملات، متابعة تلقائية، ومراقبة زمن الاستجابة.
- **Copilot:** مساعد داخلي يجيب عن أسئلة الفريق حول بيانات النشاط.
- **الفريق والفوترة:** أدوار (مالك، مدير، مشرف، عضو، قراءة فقط)، مفاتيح API، واشتراك عبر Stripe.

## التقنيات

| المجال | التقنية |
|---|---|
| الواجهة والخادم | Next.js 16، React 19، TypeScript |
| التصميم | Tailwind CSS 4، خط IBM Plex Sans Arabic |
| قاعدة البيانات | PostgreSQL مع Row Level Security |
| المصادقة | نظام دخول خاص: bcrypt وجلسات JWT موقّعة في ملف تعريف ارتباط HttpOnly |
| الذكاء الاصطناعي | Google Gemini |
| القنوات | Meta Graph API، Twilio، Vapi |
| الدفع | Stripe |
| الاستضافة | Railway |

## التشغيل محلياً

المتطلبات: Node.js 22 أو أحدث، PostgreSQL 14 أو أحدث، وBun لتشغيل الاختبارات.

```sh
npm install
cp .env.example apps/web/.env.local     # ثم عدّل القيم
createdb frontdesk
DATABASE_URL=postgres://postgres:postgres@127.0.0.1:5432/frontdesk npm run db:migrate
npm run dev
```

القيم الأساسية في `apps/web/.env.local`:

| المتغير | الوصف |
|---|---|
| `DATABASE_URL` | رابط قاعدة PostgreSQL |
| `AUTH_SECRET` | سر توقيع الجلسات (`openssl rand -base64 48`) |
| `CREDENTIAL_ENCRYPTION_KEY` | مفتاح تشفير بيانات اعتماد القنوات، 32 بايت بصيغة base64 |
| `NEXT_PUBLIC_SITE_URL` | الرابط العام للتطبيق |
| `GEMINI_API_KEY` | مفتاح نموذج الذكاء الاصطناعي |

بقية المتغيرات (Meta وTwilio وVapi وStripe وCRON_SECRET) موضحة في `.env.example`.

## الأوامر

| الأمر | الوظيفة |
|---|---|
| `npm run dev` | خادم التطوير |
| `npm run build` | بناء نسخة الإنتاج |
| `npm run start` | تشغيل نسخة الإنتاج |
| `npm run lint` / `npm run typecheck` | الفحص الثابت |
| `npm test` | الاختبارات (Bun) |
| `npm run db:migrate` / `npm run db:status` | تطبيق الترحيلات وعرض حالتها |
| `npm run db:import` | نقل البيانات من قاعدة Postgres سابقة |
| `npm run db:reset-password -- <email>` | تعيين كلمة مرور جديدة لحساب |

## الأمان

- كلمات المرور مخزنة بـ bcrypt، والجلسات تُلغى عند تغيير كلمة المرور.
- كل استعلام من المستخدم يمر عبر Row Level Security بهوية المستخدم ومؤسسته.
- بيانات اعتماد القنوات مشفرة بـ AES-256-GCM.
- كل webhook يتحقق من التوقيع أو السر، ويرفض الطلب إذا لم يُضبط السر.
